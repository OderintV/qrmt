QRMT Project Proposal, Group 12

Research Question: 
What is the probability that the number of passengers present at Azadpur Metro station exceeds a predefined threshold during peak hours, and how can probability distributions and Monte Carlo simulation be used to estimate this likelihood?

Mathematical Concepts to be applied
•	To model the number of passengers arriving at the station over fixed intervals, we’re planning on using a Poisson Distribution. 
•	Estimating the average passenger arrivals and variance in passenger number using concepts like expectation, variance and standard deviation. 
•	Generating multiple possibilities for a larger sample size using Monte Carlo simulations. 
This model will account for passenger arrivals and departures using either available data from public websites or sample data. We aim to estimate the probability of exceeding the threshold across different intervals during peak hours.
The expected outcome is a probability-based model that estimates the likelihood of passenger accumulation exceeding a predefined threshold at Azadpur Metro Station station during peak hours.
